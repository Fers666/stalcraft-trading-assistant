# SC Trading · мобильный прототип «Терминал»

Кликабельный HTML/CSS/JS-прототип **мобильной версии** интерфейса SC Trading.
Работает по `file://` без сборки и сервера (интернет нужен только для Google Fonts
и иконок предметов EXBO). Тот же функционал, что в десктопе, — переложенный на
мобильную раскладку по лучшим практикам мобильных приложений.

**Зачем:** десктоп-портал (`design/v5`, `frontend/src`) сделан под `min-width: 1240px`;
на телефоне формы «плывут» и уходят за край. Это — первый мобильный дизайн под телефон.
Замысел: зашёл с компа → десктоп, с телефона → эта мобильная версия.

## Как смотреть

Открой на телефоне (или в узком окне браузера / DevTools device mode, 360–430px):
- **`app/index.html`** — публичный лендинг → «Войти» → приложение.
- Быстрый вход в терминал: **`app/favorites.html`** (эталон).

Демо-тариф живёт в `localStorage` (`sc_demo_tier`, `sc_demo_radar`).
Переключатель — в нижнем таб-баре **«Ещё» → Демо-режим · тариф**: меняет замки на
Лотах / Закупках / Радаре и лимиты без перезагрузки.

### Тест с реального телефона (та же Wi-Fi сеть)
```powershell
cd D:\SC_AUC\design\mobile
npx --yes serve -l 8080
```
→ открой `http://<IP-компа>:8080/app/index.html` с телефона.

## Навигация

- **Верхний минибар** (fixed): бренд · бейдж тарифа · выброс · Настройки · Выход.
- **Нижний таб-бар** (fixed, 5 слотов): Избранное · Каталог · Лоты · Закупки · **Ещё**.
- **«Ещё»** (bottom sheet): Лента · Новости · Радар рынка · Настройки · Помощь · Админ ·
  Выход + демо-переключатель тарифа.

## Устройство

Переиспользует ассеты десктопного прототипа `design/v5` как единый источник правды:
- `../v5/assets/tokens.css` — цвета/шрифты/радиусы/motion (**verbatim**, новых хексов нет).
- `../v5/assets/data.js` — реальные данные срезов.
- `../v5/assets/app.js` — `SC_APP`: форматтеры, сортировка, `armConfirm`, модалка, тост.
- `../v5/assets/charts.js` — `SC_CHARTS`: SVG-графики (нужен только Избранному).

Мобильное — только раскладка:
- `assets/mobile.css` — reset (БЕЗ `min-width`) + мобильный словарь: минибар, таб-бар,
  bottom-sheet (`.msheet`), карточки-из-строк (`.dcard`), статус-сетка, стопки секций.
- `assets/mshell.js` — `SC_MSHELL`: минибар + сигналы + таб-бар + шит «Ещё» + sysbar +
  гейтинг тарифов (зеркало `v5/shell.js`).

## Инварианты «Терминала» (сохранены)

Радиусы ≤4px, без теней-глубины (слои `--s0…--s3` + границы), золото — единственный
акцент с одним «пиком» `--gold-hi` на экран; Rajdhani-заголовки / JetBrains Mono-данные
(tabular, right-align) / Inter-проза; статусные цвета — только статусы, `--q-*` — только
качество. Удаление строк — двухшаговое `armConfirm` («Точно?», 3 с), без `confirm()`.
Тач-цели ≥44px, инпуты 16px (антизум iOS), `env(safe-area-inset-*)`.

## Известные упрощения прототипа (не баги)

- Данные детерминированно «доращиваются» от реальных срезов (как в `design/v5`):
  каталог/лоты вне избранного — от категорийных медиан; закупки/новости/пользователи —
  демо-наборы.
- «Лента» — заглушка (в проде раздел тоже в разработке).
- Демо-роль администратора включена (`IS_ADMIN = true` в `mshell.js`/`admin.js`) — раздел
  «Админ» виден в «Ещё».
